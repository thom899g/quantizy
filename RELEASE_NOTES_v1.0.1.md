# Quantizy V1.0.1

This hotfix rebuilds the signed Apple Silicon app from the latest tested core.

## Included

- DeepSeek method audit covering MLA, DSA, Engram, Memory Grafting, and dynamic
  3-bit baseline evidence.
- Fixed adaptive latent cold-tail options being dropped by MLX export
  preflight/retry paths.
- Receipt-gated sparse/latent runtime planning remains unchanged: unsupported
  model integrations are not silently enabled.
- Full regression suite: `939 passed, 2 warnings`.
